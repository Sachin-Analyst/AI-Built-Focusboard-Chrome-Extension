## Installation

To install FocusBoard as a Chrome Extension on your browser:

1. *Clone the repository:*
```bash
   git clone https://github.com/Sachin-Analyst/AI-Built-Focusboard-Chrome-Extension
```
   - Open terminal and run the command above

2. *Open Chrome Extensions page:*
   - Go to `chrome://extensions` in your browser
   - Enable **Developer Mode** using the toggle in the top right corner

3. *Load the Extension:*
   - Click **"Load unpacked"**
   - Select the `AI-Built-Focusboard-Chrome-Extension` folder you just cloned

4. *Open a New Tab:*
   - FocusBoard will now appear every time you open a new tab
   - Set your focus goal, add your tasks, and start your day

## Usage

### What You Can Explore

- Set your **Today's Focus Goal** at the start of each day
- Add and manage tasks across **Work**, **Personal**, and **Learning** categories
- Mark tasks as **Completed**, **Unfinished Excellence**, or leave them in progress
- Use the **Task Matrix** to prioritise by urgency vs importance
- Track time spent on each category with the **Time Logger**
- Enable **Focus Mode** to block distracting websites
- Let the **Quote of the Day** set your mindset every morning — powered by AI, zero effort required

## The Philosophy

This extension was not built to add more to your day. It was built to direct what you already have.
